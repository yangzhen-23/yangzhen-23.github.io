# YangZhen 个人主页与博客设计说明

日期：2026-08-11

## 目标

为 GitHub 用户 `yangzhen-23` 建立一个中文为主、可长期维护的综合网站，并发布到 `https://yangzhen-23.github.io/`。网站同时承担个人主页、项目陈列和技术博客三种用途。首版必须适配电脑与手机，并让没有前端基础的站主可以通过 Markdown 持续发布文章。

## 设计原则

- 参考 Cyan's Blog 的大幅首页、内容卡片和博客信息架构，但不复制其个人文案、图片或完整视觉表达。
- 采用“山海数字花园”的完整结构与深色科技配色，整体保持经典、克制，避免过度发光、视差和复杂动画。
- 阅读优先：正文使用接近黑蓝的背景、柔和白色文字、明确的标题层级和舒适行宽。
- 内容真实：只展示已经确认的身份信息和公开 GitHub 数据，不编造教育、研究或工作经历。
- 维护简单：文章以 Markdown/MDX 保存；构建、部署和站点索引自动完成。

## 技术架构

使用 Astro 构建静态网站，博客文章由 Astro Content Collections 管理，样式使用项目内 CSS，少量交互使用原生 JavaScript。GitHub Actions 在 `main` 分支更新后构建站点，并部署到 GitHub Pages。

网站不需要数据库、登录系统或常驻服务器。构建时读取本地项目数据，浏览器只接收生成后的静态 HTML、CSS、JavaScript 和资源文件。

## 页面与组件

### 全站框架

- 顶部导航：站点名称、首页、项目、博客、关于和搜索入口。
- 移动端导航：小屏幕折叠菜单，支持键盘和触摸操作。
- 页脚：版权年份、GitHub、ORCID、RSS 与邮箱入口。
- 统一元数据：页面标题、摘要、Canonical URL、Open Graph、站点图标和结构化数据。

### 首页

- 首屏使用低对比度深蓝渐变和细微网格纹理，不使用浮夸粒子动画。
- 显示 `YangZhen`、一句简短的探索主题文案、GitHub 与“开始阅读”按钮。
- 头像使用 GitHub 公共头像地址，保留本地回退图标。
- 首屏下方依次显示简短引语、精选项目、最新文章和联系方式。

### 项目页

- 首版展示 4–6 个公开仓库，优先选择 `MoireDet`、`Academic-Detective`、`nature-skills`、`AutoEmailSender`、`Mineradio` 和 `RL_SuperMario`。
- 每张卡片包含项目名、简短中文说明、技术标签和 GitHub 链接。
- 项目说明只依据公开仓库信息；信息不足时使用保守描述。

### 博客页与文章页

- 博客列表支持分类、标签、归档和站内搜索。
- 文章页包含发布日期、更新时间、阅读时间、目录、上一篇/下一篇与返回顶部。
- Markdown 支持代码高亮、数学公式、表格、引用和本地图片。
- 提供 RSS 与站点地图。

### 关于页

- 展示名称 `YangZhen`、GitHub 用户名 `yangzhen-23`、邮箱 `yangzhen@stu.ncst.edu.cn` 和 ORCID `0009-0004-3322-2117`。
- 不展示未经确认的学校、专业、奖项或研究经历。

### 404 页面

- 提供清楚的错误提示、返回首页和进入博客的入口。
- 与全站视觉一致，不加载额外依赖。

## 视觉规范

- 主背景：炭黑与深海军蓝；表面层使用略浅蓝灰。
- 强调色：克制的靛蓝与冷蓝；仅用于链接、按钮、焦点和小面积渐变。
- 正文字体优先系统中文无衬线字体；文章大标题可使用系统中文衬线字体形成经典感。
- 卡片使用细边框、轻阴影和中等圆角，不使用大面积玻璃拟态。
- 动画限于淡入、轻微位移和悬停反馈，并遵守 `prefers-reduced-motion`。
- 对比度、焦点样式和可点击区域满足常见无障碍要求。

## 内容与数据流

1. 站主在 `src/content/blog/` 新增 Markdown/MDX 文件和文章图片。
2. Astro 在构建时校验标题、摘要、日期、分类、标签和草稿状态。
3. 内容集合生成文章页、列表、分类、标签、归档、RSS 和搜索索引。
4. GitHub Actions 执行检查和生产构建。
5. 构建产物发布到 GitHub Pages，访客通过公开 URL 访问。

## 错误处理与回退

- 缺少或错误的文章元数据会让构建失败，并给出文件与字段提示。
- 图片使用固定尺寸或宽高比，加载失败时不破坏正文布局。
- GitHub 头像或外部链接不可用时，仍显示名称、首字母占位和普通文本链接。
- 搜索脚本不可用时，文章列表、分类、标签和归档仍可直接导航。
- JavaScript 被禁用时，核心内容和页面跳转仍然可用。

## 验证标准

- `npm run check` 通过 Astro 和 TypeScript 检查。
- `npm test` 验证内容工具、筛选逻辑和关键数据结构。
- `npm run build` 成功，并生成首页、项目、博客、文章、标签、分类、归档、RSS、站点地图和 404 页面。
- 检查构建产物中不存在空链接、遗漏图片或错误的站内绝对路径。
- 使用自动化浏览器验证主要桌面与移动视口、导航、文章目录、搜索和键盘焦点。
- 文章事实与数字逐项对照源材料，个人评价与事实陈述明确区分。

## 发布边界

本地实现、测试和 Git 仓库准备可以自主完成。创建或覆盖远程 `yangzhen-23.github.io` 仓库、推送代码和启用 GitHub Pages 属于外部发布动作；执行前确认目标仓库状态，避免覆盖已有内容。若该仓库不存在，则创建同名公开仓库；若已存在，则先检查并保留已有文件。
