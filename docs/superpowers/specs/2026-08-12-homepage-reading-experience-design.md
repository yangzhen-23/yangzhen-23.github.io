# 主页与文章阅读体验微调设计

## 目标

在不改变现有深色、克制、经典视觉语言的前提下，增强主页的个人表达和文章页的阅读控制。动效参考用户给出的博客主页，只吸收循环打字节奏，不复制其主题或布局。

## 主页调整

1. 桌面端和移动端导航顺序统一为：首页、博客、项目、归档、关于、搜索。
2. 主标题保持两行“探索、记录，\n也保持好奇”，删除末尾句号。
3. 首屏说明改为循环语录区。它从独立的短句池随机选句，按“逐字输入 → 停留 → 逐字删除 → 下一句”循环。
4. 下方大语录使用另一组更完整的中文语录，以相同状态机循环。两个区域不会使用同一句文本。
5. 语录内容围绕求真、记录、研究、好奇、行动和成长，保持自然中文表达，不使用励志口号堆砌。
6. 页面首次渲染保留一条完整静态句，避免禁用 JavaScript 时出现空白；脚本接管后才开始循环。
7. “最新文章”整体移动到“精选项目”之前，其余卡片样式不变。

## 打字动画

- 使用原生 TypeScript/DOM，不增加第三方依赖。
- 每个字以轻微随机间隔出现，删除速度略快于输入速度。
- 输入完成后停留约 2.4 秒，删除完成后短暂停顿再切换。
- 文本后显示细小闪烁光标；光标不参与屏幕阅读器朗读。
- 使用 Fisher–Yates 洗牌后的播放队列，尽量避免连续重复。
- 当系统设置 `prefers-reduced-motion: reduce` 时，直接显示一次随机完整语录，不播放输入或删除动画。
- 切换标签页或离开页面时清理计时器，防止重复初始化和资源泄漏。

## 文章阅读工具

在博客文章页右下角提供固定的折叠式工具栏，不出现在普通页面：

1. 主按钮用于展开或收起工具栏。
2. 回到顶部按钮平滑滚动到页面顶部；减少动态模式下立即跳转。
3. 正文字号提供“小 / 中 / 大”三档，默认中等。
4. 正文宽度提供“窄 / 宽”两档，默认窄版；宽版仅在桌面端扩大正文和整体阅读区域。
5. 目录提供“显示 / 隐藏”切换；隐藏目录后正文自动居中占用可用宽度。
6. 字号、宽度、目录状态以及工具栏开合状态写入 `localStorage`，后续访问同一浏览器时恢复。
7. 当前选项用 `aria-pressed` 和视觉高亮表达，按钮具备中文可访问名称。
8. 移动端仅显示紧凑主按钮；展开后以小型面板显示控制项。由于现有目录在移动端不展示，目录按钮同步隐藏。
9. 工具栏避开页面边缘和正文，确保键盘可操作，并尊重安全区。

## 代码边界

- `src/data/quotes.ts`：只保存两组语录数据。
- `src/lib/typewriter.ts`：纯状态逻辑、洗牌和时序配置，便于测试。
- `src/components/TypewriterText.astro`：DOM 增强、可访问性和动画生命周期。
- `src/components/ReadingToolbar.astro`：文章页阅读设置和持久化。
- `src/pages/index.astro`：布局顺序、标题和两个语录组件。
- `src/components/Header.astro`：导航顺序。
- `src/layouts/BlogPostLayout.astro`：挂载阅读工具并响应状态属性。

## 验收标准

- 导航顺序与需求一致，当前页面状态仍正确。
- 首页标题末尾无句号，文章列表位于项目列表之前。
- 两处文字均能完成输入、停留、删除、换句循环，且语料来源不同。
- 减少动态模式下不运行循环动画。
- 阅读工具的所有选项即时生效，刷新文章页后设置仍保留。
- 目录关闭时正文布局无空洞；宽版和字号在桌面端清晰可辨，移动端不溢出。
- Astro 检查、单元测试、静态构建和构建产物验证全部通过。
